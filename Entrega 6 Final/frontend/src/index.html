Comandos para la Demo en Vivo

Defensa Oral

Comandos listos para ejecutar durante la presentacion y defensa oral:

1. Levantar las 6 capas integradas: docker compose up -d --build Inicia Service Registry, RabbitMQ, Auditoria, Backend Seguro y Gateway TLS.
2. Ejecutar Demo en Vivo de Punta a Punta (6 Capas): .\scripts\demo-en-vivo-e2e.ps1 Recorre y verifica automaticamente Infraestructura, Comunicacion, Middleware, Seguridad y Escalabilidad.
3. Escalar horizontalmente y balancear carga: curl -X POST http://localhost:5000/api/v1/scalability/scale-cluster Escala el pool a 4 instancias y demuestra reparto Round-Robin.
4. Consultar metricas de Cache L1 y Circuit Breaker: curl http://localhost:5000/api/v1/scalability/metrics Muestra Cache Hits, Hit Ratio (%), invalidaciones y estado del Circuit Breaker.
