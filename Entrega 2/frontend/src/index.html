Guía Rápida para el Docente

Pruebas en Vivo

Ejecuta estos comandos en tu terminal para validar la independencia en tiempo real:

1. Detener solo el Nodo 1 (Backend): docker compose stop backend El frontend continúa vivo y el panel muestra el cambio de estado en vivo.
2. Reactivar el Nodo 1: docker compose start backend El frontend detecta la reconexión instantánea sin necesidad de recargar la página.
3. Probar el Backend sin Frontend: docker compose stop frontend curl http://localhost:5000/health El Backend responde sus endpoints REST aún con el Frontend apagado.
